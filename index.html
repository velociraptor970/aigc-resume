PS-AI 插件协作反馈

现公司 PS-AI 协作反馈（已脱敏）与吉比特阶段 PS-AI 视觉试验：早期做过场景与角色方向的 PS-AI 视觉实验，验证局部重绘、风格调整和图像生成在概念探索中的可用性；现公司阶段协助 PS-AI 同事梳理 ComfyUI 工作流参考、提示词文案经验和功能验收标准，围绕高清去噪、局部重绘 / 涂抹区域等真实美术需求，把前期插件经验转化为可落地的功能建议。

背景
美术同学需要在 Photoshop 内完成局部重绘、降噪和边缘处理，减少传统工具链来回切换。

PS-AI 的价值应落在真实修图场景：涂抹区域控制、局部内容重绘、高清去噪、边缘抠图和提示词模板。
流程
结合前公司插件经验与吉比特视觉实验，整理功能方向、ComfyUI 工作流参考、提示词文案和验收标准。
结果
现公司协作中形成高清去噪、局部重绘、软/硬边缘抠图等功能方向，支持 PS-AI 同事继续开发与验收。
证据

结果

从项目阴影需求、方案判断、Blender 烘焙到 Photoshop 图层交付，把空间层次、AO 和阴影关系沉淀成稳定可复用流程。

背景
项目素材需要更稳定的阴影、AO 和空间层次，早期纯算法假阴影方案难以覆盖复杂遮挡与物体关系。

结果

Matting Workflow

软 / 硬边缘抠图效果

项目反馈与流程沉淀（已脱敏）：软 / 硬边缘抠图用于毛发、半透明边缘、带阴影素材和批量素材处理后，项目组确认效果好用；同时沉淀本地批量运行说明，便于项目组稳定复用。

背景
项目长期需要处理毛发、半透明边缘、带阴影素材和动画素材，传统抠图容易出现边缘脏、效率慢的问题。
判断
把硬边缘与软边缘分开处理，并把透明底、边缘校色和批量运行稳定性作为主要质量标准。
流程
用双重抠图节点提取透明底，再叠加边缘校色与半透明处理，沉淀本地批量运行说明。
结果
软边缘抠图稳定支持长期动画素材需求，并被其他组咨询复用。
证据
批量运行文档、项目好评截图、带阴影版本反馈、跨组咨询截图。

LoRA / Style Fit

LoRA 风格适配结果

展示参考图整理、训练/调试流程、生成批次对比和项目美术反馈；项目名不公开时统一以“成熟商业项目”脱敏呈现。

背景
项目风格要求具体，通用模型容易在配色、造型、线条、材质和光影上偏离目标。
判断
先判断需求是否值得训练 LoRA：如果目标风格稳定、复用频率高、参考素材充足，就适合进入训练和批量测试。
流程
参考图整理 -> 数据集处理 -> LoRA 训练/微调 -> 多批次生成 -> 美术反馈筛选 -> 接入工作流。
结果
支持成熟商业项目和在研项目的风格适配需求，帮助生成结果更接近项目可用标准。
证据
M88 场景画风训练文档、生成批次对比、项目需求记录与反馈截图。
